# Auto Weapon Sheath

Let's face it: running with a gigantic weapon in one hand looks a bit silly.

This addon sheaths your weapons when you leave combat. It works on WoW Retail and WoW Forever.

**NOTE:** This is a best effort approach and not guaranteed to work 100% of the time, since there is no real, direct game action to sheath weapons.

Sheathing cannot happen in the same moment combat ends. If you have a ranged weapon equipped, it is drawn briefly and then put away.
